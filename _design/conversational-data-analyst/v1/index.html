My recommendation

If the goal is to score well on this specific brief, I would take C · Vault, and steal one thing from each of the others.

  • Why C. The brief's most heavily weighted line is "should not allow unrestricted AI-generated SQL to execute without validation or control." C is the only direction where an interviewer sees the generated SQL, the routed tables, the five safety checks and the read-only status without clicking anything. The design itself is the evidence.
  • Steal from A: the schema rail. Showing which of the four tables were used, and which were skipped, makes the routing step visible — another explicit requirement.
  • Steal from B: the "assumptions made" card. Stating that "top five" was read as ORDER BY value DESC LIMIT 5 is the single most senior-looking detail in all three mocks.
  • Counter-argument, honestly. If the panel is non-technical, B wins on first impression. C looks like a tool for engineers; B looks like an answer for a manager.
